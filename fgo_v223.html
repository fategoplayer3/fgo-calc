使い方
  1. 「対象」 アイコンをクリックしてサーヴァントを選択、 各バフ欄をクリックして数値入力。
  2. クラス相性・属性相性 を入力 (クラス補正は自動)、 カードと クリ有無を選択 (N=宝具、 「全/半」 = 全体攻撃クリ/非クリ でダメージ半減)。
  3. 「操作」 → 「↓にコピーして行追加」 で 次ターン用の行を追加。
  4. 「データ管理」 から CSV エクスポート/インポートと ブラウザへの 保存/読込 が可能 (Mobile 版と共通フォーマット)。
  5. 計算結果のスクリーンショットは SNS 等で自由に共有可能。
  6. 各行 「操作」 ボタンから 行操作 (コピー / 入れ替え / 削除 等) や 被ダメージ計算 モード切替が可能 (詳細は 高度な使い方 へ)。
  7. グランドスコアは参考値です。
    効果の発動タイミングやバフの枠 (攻撃力 / 特攻 / カード威力 等) に未確定な部分が残っています。
    実際の値と異なる場合は、 各バフ欄をクリックして表示されるバフ詳細から、 グランドスコアの行を個別に修正・削除してください。
高度な使い方
  1. PC 版 ↔ Mobile 版 切替: 右上の 「📱」 アイコン (PC 版) / 「💻 PC版へ」 (Mobile 版) でレイアウト切替可能。 状態は自動継承されないため、 切替前に「データ管理」 → 「保存」、 切替後に「読込」 で復元 (CSV エクスポート/インポートでも引き継ぎ可能)。
  2. 「操作」 メニュー: 各行の「操作」 ボタンから利用可能 — コピー (↓に / ↑に / 空行を追加)、 入れ替え (↓ / ↑)、 リセット、 削除、 被ダメージ計算 モード切替。
  3. 被ダメージ計算モード: 「操作」 メニュー最下部の「☐ 被ダメージ計算」 をクリックすると、 その行が「敵から受けるダメージ」 を計算するモードに切り替わります (行背景が薄赤に変化)。 もう一度クリックで通常モードに戻ります。
  4. 「表示切替」→「位置別追加バフを表示」 をオンにすると、カード位置 (1st/2nd/3rd/EX) 別の追加バフ入力欄が表示されます。
    メイン入力に加算される形で、特定カードでのみ効くバフ・デバフを再現できます。
    例: 神通力（夏）「クリ攻撃時に攻撃力 +10% (3T) を付与」を 1st クリ発動と想定 → 攻撃バフの 2nd/3rd/EX 追加欄に 10 を入力 → 1st は加算なし、2nd 以降に +10% が乗る。
  5. バフ詳細入力ウィンドウ左下の「📋 プリセット ▾」から、よく使うバフ一式に名前を付けて保存・呼び出しできます (攻撃バフ・Bバフ等フィールドごとに独立)。
    「管理」ウィンドウでは名前変更・削除や JSON/CSV でのバックアップ・他端末への移行が可能です。
  6. スペース・イシュタルやプトレマイオスのように宝具を換装できるサーヴァントは宝具名の部分をクリックして別の宝具に切り替えることが可能です。
